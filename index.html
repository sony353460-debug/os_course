Project Nexus: 自動化維運平台

OS 期末實作：整合式 LAMP Stack 與自動化維運架構

專案綜述

本專案旨在解決傳統 Web 伺服器在維護上的痛點。我們透過自動化腳本實作了一套具備自我修復與資源管理功能的系統，確保 WordPress 服務能在最小化人力介入的情況下維持長期穩定運行。

技術規格與達成

自動化維運 (Automation)

  • DB 備份： 每日自動化 MySQL dump。
  • 空間管理： 整合 find -mtime +30 策略。
  • 系統監控： 磁碟空間閾值預警 (90%)。

資安與部署 (Security)

  • 權限治理： 符合最小權限原則。
  • Rewrite 模組： 乾淨且 SEO 友善的 URL。
  • 環境一致性： 透過 Git 控制配置。
